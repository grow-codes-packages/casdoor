# Casdoor SDK (Grow Codes)

One API for Casdoor in five languages (categories: auth). Pick the package for the
project's language, configure it from the environment, and handle errors by their canonical code.

## 1. Add the package

| Language | Command | Import |
| - | - | - |
| TypeScript | `npm install @grow-codes/casdoor` | `import { CasdoorClient } from "@grow-codes/casdoor"` |
| Rust | `cargo add grow-casdoor` (add `tokio` with `macros,rt-multi-thread`) | `use grow_casdoor::CasdoorClient;` |
| Go | `go get github.com/grow-codes-packages/casdoor/go` | `casdoor "github.com/grow-codes-packages/casdoor/go"` |
| Python | `pip install grow-casdoor` (or `uv add grow-casdoor`) | `from grow_casdoor import CasdoorClient` |
| Java | Maven `codes.grow.packages:casdoor` (Gradle `implementation("codes.grow.packages:casdoor:<version>")`) | `import codes.grow.packages.casdoor.CasdoorClient;` |

Check the latest version in the README badges before pinning one.

## 2. Configure

Prefer environment configuration so no credential is written into code:

```sh
export GROW_AUTH_ISSUER=http://casdoor:8000          # or GROW_CASDOOR_URL
export GROW_AUTH_CLIENT_ID=... GROW_AUTH_CLIENT_SECRET=...   # from your secret store, never committed
export GROW_AUTH_ORG=... GROW_AUTH_APP=... GROW_AUTH_REDIRECT_URL=...
```

Precedence: explicit config value > `GROW_CASDOOR_*` > vendor variables (`GROW_AUTH_ISSUER`/`GROW_AUTH_PUBLIC_URL`, `GROW_AUTH_CLIENT_ID`, `GROW_AUTH_CLIENT_SECRET`, `GROW_AUTH_ORG`, `GROW_AUTH_APP`, `GROW_AUTH_REDIRECT_URL`, `CASDOOR_ADMIN_PASSWORD`, `GROW_CASDOOR_*`) > default.
Other variables: `…_CONNECT_TIMEOUT`, `…_REQUEST_TIMEOUT`, `…_TOTAL_TIMEOUT` (`10s`, `1500`),
`…_MAX_RETRIES`, `…_CA_CERT`, `…_CLIENT_CERT`, `…_CLIENT_KEY`, `…_PROXY`. Environment proxies
(`HTTPS_PROXY`) are ignored unless `proxy` is set.

## 3. Use

Create one client per process and close it on shutdown (TypeScript `await client.close()`, Rust
`client.close().await`, Go `defer client.Close()`, Python `with …`/`close()`, Java
try-with-resources).

- `health()` never throws for an unhealthy service; check `healthy`.
- `ping()` verifies credentials (`AUTHENTICATION` error when they are wrong).
- All I/O is retried with jitter on 429/502/503/504 and connection errors; only idempotent calls
  are retried on 500.
- Errors carry `code` (`CONFIG`, `AUTHENTICATION`, `PERMISSION_DENIED`, `NOT_FOUND`, `CONFLICT`,
  `RATE_LIMITED`, `VALIDATION`, `UNAVAILABLE`, `TIMEOUT`, `UNSUPPORTED`, `CANCELLED`), `retryable`,
  `httpStatus` and `requestId`. Branch on the code, not on the message text. Go:
  `errors.Is(err, casdoor.ErrNotFound)`.

### Casdoor functions

Exact API, env names, error reasons and Casdoor quirks: `AGENTS.md` inside the installed package
(`node_modules/@grow-codes/casdoor/AGENTS.md`, Go module root, `grow_casdoor/AGENTS.md`, crate root,
jar `META-INF/grow/casdoor/AGENTS.md`). Typical BFF use:

```ts
const casdoor = CasdoorClient.fromEnv();
const tokens = await casdoor.signIn({ username: email, password, totpCode });   // MfaRequiredError → ask for the code
await casdoor.signUp({ email, password }); await casdoor.sendEmailVerification(email);
await casdoor.verifyEmail({ email, code });
await casdoor.forgotPassword(email); await casdoor.resetPassword({ email, code, newPassword });
```

Identity setup (platform, tests): `ensureOrganization`, `ensureApplication`, `ensureEmailProvider`,
`ensureRoles`, `ensureUser`, `assignRoles` with `GROW_CASDOOR_ADMIN_PASSWORD`/`CASDOOR_ADMIN_PASSWORD`.

## 4. Test code that uses the SDK

Use the in-memory fakes from the testing module instead of a real Casdoor in unit tests:
TypeScript `@grow-codes/casdoor/testing`, Rust feature `testing`, Go package `testkit`, Python
`grow_casdoor.testing`, Java `codes.grow.packages.casdoor.testing`.

## 5. Work on this repository

Read `AGENTS.md` first. Short version: the five languages keep the same API; files with the
`Generated by sdk-kit` header are changed in sdk-kit, not here; `make lint coverage` must pass
(≥ 90 % lines and branches); `make test-docker LANGS="<lang>"` runs the integration suite against
`casbin/casdoor:v4.27.1`.
